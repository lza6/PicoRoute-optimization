# Project Specifications - PicoRoute

## Project Goal
Create the world's most performant, feature-rich, and beautiful **single-file** PHP framework.

## Tech Stack
- **Language**: PHP 8.0+
- **Database**: SQL (via PDO)
- **Dependencies**: ZERO (Native PHP only)
- **Architecture**: MVC (Micro-kernel)

## Design Guidelines
- **Visuals**: "Holographic" Design. Dark mode default. Smooth animations.
- **Code**: Strict Types (`declare(strict_types=1)`). PSR-12ish (adapted for single file).
- **Philosophy**: "One File, Infinite Possibilities".
- **Internationalization**: Support for multiple languages with easy switching.
- **Accessibility**: Ensuring all UI elements are accessible and properly localized.
